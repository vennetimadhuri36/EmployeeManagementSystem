# EmployeeManagementSystem
Full-stack Employee Management System built using ASP.NET Core Web API, ASP.NET Core MVC, Entity Framework Core, and SQL Server. Features include CRUD operations, employee search, input validation, LINQ queries, Repository Pattern, and REST API integration using HttpClient. APIs are tested using Swagger.


## Technologies Used
- C#
- ASP.NET Core Web API
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- LINQ
- Repository Pattern
- Swagger
- HttpClient
- Bootstrap

## Features
- View employee records
- Add employees
- Edit employee details
- Delete employees
- Search employees
- Input validation
- REST API integration

## Setup
1. Clone this repository.
2. Open the solution file in Visual Studio.
3. Configure your local SQL Server connection string.
4. Apply Entity Framework migrations if required.
5. Run the API project.
6. Run the MVC project and verify the API base URL.

## Project Purpose
Created as a practical project to develop and demonstrate ASP.NET Core development skills.
